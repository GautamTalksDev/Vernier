# Support

## How to get help

- Check [README.md](README.md) for install and usage basics.
- Check [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) for system shape.
- Search existing GitHub issues before opening a new one.

## Bug reports

Open an issue with:

- Vernier version (`uv run vern --help` / package version)
- OS and Python version
- Exact command run
- Expected vs actual behaviour
- Minimal reproduction, if possible

## Security issues

See [SECURITY.md](SECURITY.md). Do not file public issues for vulnerabilities.

## What is not supported

Feature requests that conflict with the Kill Tests in [README.md](README.md),
or that would make comparison/classification non-deterministic, will be
declined. Capture ideas you will not build in [IDEAS.md](IDEAS.md).
