# Succession

Vernier is currently a single-maintainer project: repository admin rights,
PyPI Trusted Publishing (OIDC), GitHub Actions environments/secrets, and any
signing keys stay with the listed GitHub owner (`GautamTalksDev`) unless and
until that person designates a successor in writing in this file or a linked
SECURITY contact. Published releases on PyPI and GitHub Releases remain
immutable artifacts of the Apache-2.0 project and do not disappear if
maintainership changes; consumers should pin versions and verify attestations
where available. If the original maintainer becomes unreachable, a fork may
continue under a new name or as a named successor repository—prefer renaming
or clear versioning so install paths and Trusted Publisher identities are not
confused with the abandoned origin—and should update this document, CODEOWNERS
(if any), and publishing credentials accordingly.
