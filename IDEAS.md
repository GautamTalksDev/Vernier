# Ideas (not built)

Parked ideas that came up while building Vernier. None of these are
implemented — they are deliberately deferred so the core stays
determinism-first.

1. **Async httpx / aiohttp capture** — only sync clients are hooked today.
2. **Browser / Playwright plane** — DOM actions as first-class trajectory events.
3. **Semantic ignore packs** — community-contributed ignore-lists per SaaS API.
4. **Interactive TUI for `vern diff`** — scrollable alignment with jump-to-rule.
5. **GitHub Action marketplace packaging** — one-liner `vern gate` for PRs.
6. **Multi-agent / swarm alignment** — align N>2 runs as a lattice, not a pair.
7. **Cost-aware replay scheduling** — prioritize high-severity candidates first.
8. **Record compression codecs beyond gzip** — zstd with fixed dictionary.
9. **Prompt-diff lens** — show only system/tool schema deltas between models.
10. **Human label UI for KT-2** — browser app to mark behavioural vs cosmetic.
11. **OpenTelemetry exporter** — emit trajectory events as OTLP (opt-in only).
12. **Policy-as-code severity overrides** — org TOML that remaps D-rules.
13. **WASM plugin tools** — sandbox unverified tools during live re-drive.
14. **Corpus anonymizer** — strip PII from recorded blobs before sharing.
